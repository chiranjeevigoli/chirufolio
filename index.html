FleetMind AI
Python · RAG · ChromaDB · Sentence Transformers · Gemini API · LangChain
+
Problem

Heavy-duty fleet maintenance manuals run thousands of pages. Technicians troubleshooting in the field can't search that fast enough, and a wrong guess is expensive.

Architecture

PyMuPDF + LangChain ingestion pipeline chunking and embedding manuals into a ChromaDB vector store, queried through a Streamlit interface backed by the Gemini API.

The hard part

Generic RAG answers confidently even when retrieval is weak. I built an agentic routing layer that scores retrieval confidence and triggers a clarifying question instead of a guess when a query is ambiguous.

Result

1,212 pages indexed into 3,795 semantic chunks, with measurably fewer incorrect answers thanks to the confidence-routing layer.

Lesson learned

The interesting engineering in RAG isn't the retrieval — it's deciding when NOT to answer.

AI Data Analyst Agent
Python · Streamlit · Gemini API · SQLAlchemy · MySQL
+
Problem

Non-technical stakeholders had CSV data and questions, but no SQL. Every ad-hoc question meant waiting on someone else's query.

Architecture

Automated schema detection translates plain-English questions into SQL, executed live against MySQL through SQLAlchemy, with results rendered as text or auto-generated charts.

The hard part

Follow-up questions ("now break that down by month") need session context — I added context-aware handling so the agent remembers prior questions within a session.

Result

Upload any CSV, ask in plain English, get a query-backed answer with a chart — no SQL required.

Lesson learned

Natural-language-to-SQL is only trustworthy if the schema detection is bulletproof — most failures traced back there, not the language model.

Asset Management System
Python · FastAPI · SQLAlchemy · MySQL · Pydantic
+
Problem

Needed a clean reference implementation of a full CRUD system with real request validation — the kind of foundation every internal tool ends up needing.

Architecture

REST API built on FastAPI with SQLAlchemy models and Pydantic request validation, using dependency-injected database sessions for testable, isolated endpoints.

The hard part

Getting session management right so endpoints stay testable in isolation rather than depending on global state.

Result

A complete, reliable CRUD API — the pattern I now reuse as a starting point for backend work.

Lesson learned

Boring, well-structured CRUD is a skill in itself — most production bugs live in the "obvious" endpoints.
