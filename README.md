# Chiranjeevi Goli — Personal Portfolio

[![Live Site](https://img.shields.io/badge/Status-Live-success)](#) 

This repository contains the source code for my personal portfolio website. I am an electronics engineer with proven experience at the intersection of hardware test rigs, software automation, and applied AI.

## 🛠️ Tech Stack & Architecture

This portfolio was built with a focus on performance, independence, and a clean aesthetic. Instead of relying on heavy frameworks, it is built entirely using vanilla web technologies:

- **HTML5**: Semantic and accessible document structure.
- **Vanilla CSS3**: Custom design system featuring CSS variables, modern grid layouts, fluid typography, and premium micro-animations (no Tailwind or external UI libraries).
- **Vanilla JavaScript**: Handles custom interactive features like the `Ctrl+K` command palette and live data fetching.
- **GSAP (GreenSock)**: Used exclusively for high-performance, scroll-triggered reveal animations.
- **GitHub API**: Dynamically fetches my latest open-source projects and real-time statistics when the page loads.

## ✨ Key Features

- **Custom Command Palette**: Press `Ctrl + K` anywhere on the site to open a quick-navigation menu.
- **Dynamic Content**: The "Open Source & Now" section is not statically typed; it pulls directly from GitHub.
- **Responsive Design**: Fluidly adapts from widescreen monitors down to mobile devices using `auto-fit` CSS grids.
- **Aesthetic Focus**: Deep dark mode theme (`#0C0F12`), accented with custom gold and teal elements.

## 🚀 How to Run Locally

Since this project has zero build steps and no external dependencies (other than a CDN link for GSAP), running it locally is incredibly simple:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/chiranjeevigoli/portfolio.git
   ```
2. **Open the project:**
   Simply double-click the `index.html` file to open it in your default web browser. 
   
   *(Alternatively, use an extension like VS Code Live Server for hot-reloading if you wish to make edits).*
